## About

DevVault is a Developer Knowledge Management Platform that acts as a personal "second brain" for developers. It allows users to store, organize, search, and reuse their notes, code snippets, learning resources, bug solutions, and project information in one centralized place.

## Tech stack

- Frontend: HTML, CSS, JavaScript
- Styling: Tailwind CSS
- Version Control: Git & GitHub
- CI/CD: GitHub Actions and Jenkins
- Backend: Not implemented yet
- Database: Not implemented yet
